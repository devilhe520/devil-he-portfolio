# Devil He Portfolio

Personal portfolio for Devil He, a Senior UX / Digital Experience Designer based in Shanghai.

The site presents selected delivery work, digital experience strategy, Global-to-China capabilities, professional experience and interests beyond work. Public case content is intentionally concise to respect project confidentiality.

## Highlights

- Chinese and English language modes
- Responsive desktop and mobile layouts
- In-page case overviews with selected public imagery
- Luxury, fashion, sports and digital consumer brand experience
- Vinext / React implementation prepared for Cloudflare hosting

## Local development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Open `http://localhost:3000/`.

## Verification

```bash
npm run lint
npm test
```

## Content note

Images and brand names are used as portfolio references. Detailed project materials remain confidential and are shared only in private interviews where appropriate.
